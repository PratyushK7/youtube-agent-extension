04 · Highlights

Selected work, from problem to result.

Scroll through each build — the diagram assembles itself as the story does.

Distributed Systems
Problem

A synchronous cmdlet couldn't keep up with audit volume.

Internal M365 tools (Insider Risk Management, DataInsights) leaned on a synchronous PowerShell cmdlet path for audit search — it didn't scale, and every query blocked on the last.

Approach

Architected JobScheduler as an async distributed engine.

Replaced the cmdlet path entirely with a purpose-built asynchronous job engine, decoupling query submission from execution.

Architecture

Parallel per-shard fan-out over sharded storage.

Per-tenant concurrency control and parallel fan-out across shards, backed by sharded Azure Table and Event Hub storage.

Result

50K+ searches and 10M+ records a day, across 12 stamps.

Now the backbone of audit search across 12 regional stamps — and the same engine that later powers the public Graph Security API.

Public API
Problem

The audit-search engine only served internal Microsoft tools.

JobScheduler was fast and reliable — but locked inside Microsoft's own products, unreachable by customers or ISV partners.

Approach

Exposed it through the Microsoft Graph Security API.

Rather than building a parallel system, the same backend was surfaced publicly — no duplicated logic, no drift between internal and external behavior.

Architecture

App & delegated OAuth, behind strict tenant isolation.

Full OAuth 2.0 support for both app and delegated auth, with RBAC and multi-tenant isolation so no tenant could ever see another's data.

Result

Adopted by 200+ external tenants and ISV apps.

The same engine built for internal audit search now powers a public, multi-tenant surface at scale.

AI / Agentic
Problem

Answering an audit question meant writing a query by hand.

Getting insight out of the audit data meant knowing the schema and hand-writing a query — a wall between the question and the answer.

Approach

Built an agentic pipeline on the Claude API.

Natural-language questions flow through intent parsing, query synthesis, and retrieval — no schema knowledge required.

Architecture

Rendering, with a self-correction loop back into the pipeline.

Results render as live visualizations; when something looks off, the loop routes back to re-synthesize the query automatically.

Result

Presented to 50+ engineering leaders at HackWeek.

Audit Analytics turned a manual, schema-bound task into a conversation — demoed live to leadership.
